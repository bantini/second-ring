# SecondRing

Giving discarded Android phones a second life. Old phones are cleaned up, made safe and handed to people who can't afford one, for calls, SMS, UPI payments and studying.

- **[PLAN.md](PLAN.md)**: the plan, from a hands-on pilot to a clean OS for older phones.
- **[clean-tool/](clean-tool/)**: "Clean this phone", a browser tool that removes bloatware over USB, applies battery-saving settings and turns off developer options. It works in English and nine Indian languages.

**Try the tool:** https://bantini.github.io/second-ring/

Open it in Chrome or Edge on a computer, or in Chrome on an Android phone with a USB OTG cable. There's a demo phone if you don't have one plugged in.

> **Pilot version:** the removal lists haven't been tested on real phones yet. Only use the tool on a phone that can be factory-reset if something goes wrong.

Problems and suggestions: [open an issue](https://github.com/bantini/second-ring/issues).
